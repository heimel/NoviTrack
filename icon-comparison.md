# NoviTrack 24 px icon comparison

This worksheet compares two candidates from four open-source 24 px icon sets for the text-heavy controls in the NoviTrack Database Browser and Track Behavior window.

Reply with a preferred set and any per-action choices using the IDs and letters below, for example: `Set: Tabler; DB-03 B; TR-07 A`.

## Candidate sets

| Set | Prefix | Style | License |
|---|---|---|---|
| [Tabler Icons](https://icon-sets.iconify.design/tabler/) | `tabler` | Outline | MIT |
| [Lucide](https://icon-sets.iconify.design/lucide/) | `lucide` | Outline | ISC |
| [Material Design Icons](https://icon-sets.iconify.design/mdi/) | `mdi` | Mixed outline/filled | Apache 2.0 |
| [Material Symbols](https://icon-sets.iconify.design/material-symbols/) | `material-symbols` | Outline Rounded candidates | Apache 2.0 |

All previews are requested from the Iconify API at 24 × 24 px. Icon names were validated against the current Iconify collections on 2026-08-29.
