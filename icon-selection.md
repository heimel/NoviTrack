# NoviTrack 24 px icon selection

This worksheet shows the selection of icons from the Lucide open-source 24 px icon set for the text-heavy controls in the NoviTrack Database Browser and Track Behavior window.

## Candidate sets

| Set                                                                    | Prefix             | Style                      | License    |
| ---------------------------------------------------------------------- | ------------------ | -------------------------- | ---------- |
| [Lucide](https://icon-sets.iconify.design/lucide/)                     | `lucide`           | Outline                    | ISC        |

All previews are requested from the Iconify API at 24 × 24 px. Icon names were validated against the current Iconify collections on 2026-08-29.

## Selection notes

The final implementation should bundle only the selected SVG files locally, retain every original label as a tooltip and accessible name, and avoid any runtime dependency on Iconify.
